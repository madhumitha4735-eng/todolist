# To-Do List

## Project Overview
The To-Do List is a simple web application developed using HTML, CSS, and JavaScript. It helps users manage their daily tasks by allowing them to add, complete, and delete tasks through an easy-to-use interface.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
```
ToDoList/
│── index.html
│── style.css
│── script.js
└── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start adding and managing your tasks.

## Future Enhancements
- Edit existing tasks
- Add task reminders
- Dark mode
- Save tasks using Local Storage
- User login and signup

## Conclusion
This project demonstrates the fundamentals of front-end web development using HTML, CSS, and JavaScript. It is suitable for beginners and can be extended with advanced features.
